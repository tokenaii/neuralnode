# Contributing to NeuralNode

Thank you for helping improve NeuralNode. Contributions may be submitted by
opening an issue, creating a fork, or opening a pull request.

## Pull request workflow

1. Create a focused branch or fork.
2. Explain the problem and the proposed change.
3. Include or update tests when appropriate.
4. Run the relevant checks locally.
5. Open a pull request against the default branch.

All pull requests are subject to review by TokenAI. Opening a pull request
does not guarantee acceptance or merge. TokenAI may accept, request changes,
reject, close, or remove a proposed contribution at its sole discretion.
